# Landing Experiment A/B Testing Analysis

A/B testing analysis project focused on conversion behavior, hypothesis testing, statistical significance, and business interpretation.

## Project Overview

This project analyzes a landing page experiment to evaluate user behavior and business performance across different experimental groups.

The analysis includes statistical testing methods commonly used in marketing analytics and product experimentation:

- t-test for comparing average spending between groups
- z-test for comparing conversion rates and proportions
- chi-square test for analyzing relationships between categorical variables
- p-value interpretation
- null hypothesis evaluation
- business interpretation of statistical results

## Business Relevance

This project is especially relevant for Marketing Data Analytics because it connects experimentation, conversion analysis, campaign evaluation, and statistical decision-making.

The goal is not only to run statistical tests, but to translate the results into insights that can support business decisions.
